# Worked Example

A complete, end-to-end run of the Launch Team for a fictional product so you can
see the system working — how a brief flows through each agent, what the outputs
look like, and how the human-approval gates show up in practice.

**Product:** *Brightside* — a $99 sunrise wake-up light (gradual light to wake
you, sunset wind-down to fall asleep). Consumer tech / home, 65% margin.

**Goal:** 600 sales / ~$59K revenue in 30 days on a $20,000 ad budget
(≈ 3.0x target ROAS — and $20K × 3.0 = $60K, so the math ties out).

## The run, in order

| # | File | Agent | Output |
|---|---|---|---|
| 01 | [`01-launch-brief.md`](brightside-launch/01-launch-brief.md) | (owner) | Filled-in launch brief |
| 02 | [`02-launchmarketing-strategy.md`](brightside-launch/02-launchmarketing-strategy.md) | launchmarketing | ICP, positioning, angles, channel plan, funnel |
| 03 | [`03-launchcreative-copy.md`](brightside-launch/03-launchcreative-copy.md) | launchcreative | Ad copy variants, LP copy, creative brief |
| 04 | [`04-launchads-campaign-plan.md`](brightside-launch/04-launchads-campaign-plan.md) | launchads | Campaign structure, audiences, budgets — **specced PAUSED, pending approval** |
| 05 | [`05-launchperformance-report.md`](brightside-launch/05-launchperformance-report.md) | launchperformance | Tracking plan, sample daily report, optimization rec, weekly rollup |
| 06 | [`06-launchteam-coordination.md`](brightside-launch/06-launchteam-coordination.md) | launchteam | Assignments, the approval gate in action, owner rollup |

> This is illustrative output, not a real campaign. Numbers are realistic
> examples, not promises. Note how `launchads` never sets anything live on its
> own (04), and how `launchteam` routes go-live and budget through an explicit
> owner approval (06) — exactly per [`../shared/human-approval-policy.md`](../shared/human-approval-policy.md).
