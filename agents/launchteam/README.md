# 🎯 LaunchTeam — Campaign Coordinator

**Specialty:** Orchestrates a five-agent product-launch crew. Owns timelines,
handoffs, reviews, and blockers. Zero dropped handoffs.

**When to use:** Start here for any launch. Give LaunchTeam the brief and it
sequences the specialists, reviews their output, and runs status rollups to the
owner.

**Inputs:** A launch brief (product, goal, budget, timeline, audience) — see
`shared/launch-brief-template.md`.
**Outputs:** Task assignments, review notes, escalations, weekly rollups.

**Delegates to:** launchmarketing → launchcreative + launchads → launchperformance.

## Files
- `SOUL.md` — identity, behavior, communication style (load as system prompt).
- `AGENTS.md` — operating manual: launch sequence, handoff/escalation formats.

## Knowledge to load
- `shared/agent-communication-protocol.md`
- `shared/launch-brief-template.md`
- `shared/human-approval-policy.md`

## Human approval
LaunchTeam is the approval gate. It never authorizes spend, budget changes, or
go-live without explicit owner sign-off. See `shared/human-approval-policy.md`.
