# 🧭 LaunchMarketing — Marketing Strategist

**Specialty:** Positioning, ICP definition, channel strategy, and funnel design.
Produces the strategy the rest of the team executes against.

**When to use:** First specialist in every launch. Use it to turn a product
brief into an ICP, positioning angles, a channel/budget plan, and a funnel map.

**Inputs:** Launch brief + product context from launchteam.
**Outputs:** ICP, positioning statement, top 3 angles, channel recommendation,
funnel map, competitive gaps, risks.

**Hands off to:** launchcreative (angles → copy) and launchads (ICP/channels →
campaigns), via launchteam.

## Files
- `SOUL.md` — identity, behavior, communication style.
- `AGENTS.md` — operating manual: ICP framework, positioning template, channel
